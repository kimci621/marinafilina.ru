# Каталог awwwards-паттернов

Выбирай **один** сигнатурный (максимум два взаимодополняющих), остальное держи скромным. Awwwards-жюри оценивает "innovation" и "creativity" вместе с "usability" — эффект без смысла для контента снижает оценку, а не повышает.

## Два разных пути к "вау"

Ниже — каталог по умолчанию: органичный motion-first подход (плавный скролл, курсор-компаньон, elastic-переходы). Он не единственный. Если бриф называет конкретный визуальный язык — например, рациональный швейцарский/ульмовский дизайн в духе Отля Айхера — "вау" делается не добавлением эффектов, а точностью системы: видимая модульная сетка, единый гротеск, нумерация как часть контента (не декор), плоские сигнальные цвета вместо градиентов, курсор как измерительный инструмент (координаты по сетке), нулевые скругления, никакого elastic/organic easing — только точные, почти механические переходы (`power`/`expo`). Это тоже сигнатурный момент, просто источник впечатления — дисциплина и точность, а не богатство эффектов. `template/` в этом скилле сейчас реализует именно этот, системный вариант — используй его как референс структуры, если бриф просит нечто подобное; для motion-first брифа адаптируй паттерны ниже.

## Вход на сайт

- **Прелоадер**: процентный счётчик (0→100%) или анимация логотипа, пока грузятся шрифты/картинки. Оправдан, только если реально что-то грузится дольше ~500мс — иначе это искусственная задержка.
- **Intro-секвенция**: заголовок собирается по буквам/словам, фон проявляется, логотип трансформируется в навигацию. Один раз при первом заходе, не при каждой навигации.

## Курсор и наведение

- **Custom cursor**: кружок/точка, которая укрупняется над интерактивными элементами, показывает подпись ("View", "Play"). Только desktop — на touch отключать.
- **Magnetic button**: элемент слегка "притягивается" к курсору в радиусе ~40-80px (сдвиг transform, не layout). Хорош для CTA и nav-иконок, не для всего подряд.
- **Image hover distortion**: лёгкий сдвиг/скейл/parallax картинки под курсором в карточках проектов. WebGL-шейдерный дисторшн — только если это реально сигнатурный момент сайта, иначе оверинжиниринг.

## Скролл

- **Smooth scroll (Lenis)**: инерционная прокрутка вместо нативной — база almost для каждого awwwards-сайта, задаёт "тактильность".
- **Scroll-triggered reveal**: секции/строки текста проявляются (opacity+translateY) при входе во viewport. Стандарт, делай через `ScrollTrigger`, не через `IntersectionObserver` с нуля, если уже используешь GSAP.
- **Pinning**: секция "прилипает" на экране, пока внутри неё проигрывается анимация/меняются слайды (частый паттерн для "process" или горизонтального скролла работ). Использовать по делу — 1 pin-секция за страницу, не превращать всю страницу в pin-цепочку.
- **Horizontal scroll section**: галерея работ едет горизонтально при вертикальном скролле пользователя. Хорошо работает для 3-6 карточек, плохо — если карточек много (пользователь теряется).
- **Parallax слоёв**: фон/декор двигается медленнее/быстрее контента. Используй умеренно — на мобильном часто отключать (перфоманс + тошнота от motion).

## Текст

- **Split-text reveal**: заголовок анимируется по буквам/словам/строкам (через GSAP SplitText или аналог). Хорошо для hero и заголовков секций, не для длинных абзацев (мешает читать).
- **Marquee/бегущая строка**: список услуг/технологий/клиентов едет бесконечной лентой. Работает как акцент, не как основной способ подачи важной информации.
- **Текст, реагирующий на скролл**: цвет/вес/заливка текста меняется по прогрессу скролла (характерно для агентских сайтов).

## Структура и переходы

- **Grid-breaking layout**: асимметричная сетка, элементы вылезают за колонку — оправдано, если это отражает контент (портфолио с разноформатными работами), а не украшательство.
- **Page/section transition**: при переходе между "страницами" (SPA-роутинг или якорные секции) — общий overlay-переход (wipe, slide), а не резкий джамп.
- **Case-study reveal**: клик по карточке работы разворачивает детальный вид (модалка на весь экран или переход на отдельный маршрут) с крупным hero-изображением проекта.
- **Grain/noise texture**: тонкий шум поверх фона (CSS `mix-blend-mode` + SVG-шум или PNG-текстура) — добавляет "плёночность", дёшево по перфомансу, часто встречается на топовых awwwards-сайтах.

## Что НЕ делать

- Не включать все паттерны сразу — итог читается как демо-каталог библиотеки анимаций, а не как дизайн с точкой зрения.
- Не анимировать то, что мешает считыванию информации (растянутые reveal на критичном CTA, дисторшн на теле кейса).
- Не игнорировать `prefers-reduced-motion` — см. `motion-gsap-lenis.md`.
