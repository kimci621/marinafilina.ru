# Чеклист перед публикацией

## Доступность и деградация

- [ ] `prefers-reduced-motion: reduce` реально отключает/упрощает анимации (проверить в devtools → Rendering → Emulate CSS media)
- [ ] Все интерактивные элементы имеют видимый `:focus-visible` (не убран `outline` без замены)
- [ ] Custom cursor не ломает нативный курсор на touch-устройствах (`pointer: coarse`)
- [ ] Контраст текста на фоне ≥ 4.5:1 для основного текста (особенно на фото/градиентах)
- [ ] Все декоративные картинки — `alt=""`, содержательные — с осмысленным `alt`

## Адаптивность

- [ ] Проверено на mobile-ширине (~375px): hero, grid работ, magnetic-кнопки (на touch magnetic отключается)
- [ ] Горизонтальный скролл/pin-секции не ломают мобильную вёрстку (часто их вообще нужно отключать <768px)
- [ ] Текст не переполняет контейнеры при длинных заголовках на разных языках

## Производительность

- [ ] Lighthouse Performance ≥ 90 на десктопе (мобильный порог ниже, но не игнорировать)
- [ ] Изображения — в современном формате (webp/avif) и с `width`/`height` атрибутами (нет CLS)
- [ ] Шрифты — `font-display: swap`, подключены только реально используемые начертания
- [ ] `ScrollTrigger.refresh()` вызывается после загрузки шрифтов/изображений (см. `motion-gsap-lenis.md`)

## SEO / мета

- [ ] `<title>` и `<meta name="description">` заполнены содержательно, не generic
- [ ] Open Graph / Twitter Card (og:title, og:image, og:description) для превью в соцсетях/мессенджерах
- [ ] favicon подключен (минимум .ico + один PNG-размер)
- [ ] Семантическая разметка (`<main>`, `<nav>`, `<section>`, заголовки по иерархии h1→h2→h3)

## Кроссбраузерность

- [ ] Проверено в Chrome, Safari, Firefox (Safari чаще всего ломает `backdrop-filter`, `position: sticky` в связке с transform-родителями)
- [ ] Проверена работа без JS (graceful fallback: контент читаем, просто без анимаций) — минимум нет "белого экрана" при ошибке скрипта
