# Template

Демо-сайт без сборки. Реализует **системное** направление из `../references/patterns.md` ("Два разных пути к 'вау'") — рациональная модульная сетка и точность вместо органичного motion-декора, в духе Отля Айхера/Ульмской школы: видимая 12-колоночная сетка, единый гротеск (Inter), плоские сигнальные цвета (мюнхенский синий + красный), нулевые скругления, курсор-визир с координатой по сетке вместо игривого magnetic-курсора.

## Запуск

Локально нужен http-сервер (не `file://`, иначе часть fetch/шрифтов может не сработать в некоторых браузерах):

```bash
cd template
python3 -m http.server 8000
# открыть http://localhost:8000
```

или `npx serve .`

## Что показывает

- Прелоадер-"калибровка": 12-сегментная линейка заполняется вместо процентного счётчика — сразу задаёт тему сетки
- Интро hero: колонки сетки прочерчиваются сверху вниз, затем заголовок проявляется жёстким clip-wipe (без elastic/organic easing)
- Custom cursor-визир: две линии на весь экран + подпись с координатой (`C04 / R12`), на интерактивных элементах подпись меняется на текст действия (`ОТКРЫТЬ`, `НАПИСАТЬ`)
- Нумерованные системные заголовки секций (01 / 02 / 03) — не декор, а сквозная навигационная логика страницы
- Работы — плоские сигнальные цвета вместо градиентов/фото-плейсхолдеров, с регистрационной меткой на hover (CSS, без JS-параллакса)
- Marquee превращён в "бегущую строку-индекс" с тик-разделителями
- Scroll-triggered reveal секций (`ScrollTrigger.batch`)
- Lenis smooth scroll, синхронизированный с GSAP ticker
- Полная деградация при `prefers-reduced-motion: reduce`

## Адаптация под реальный бриф

1. Замени контент (имя, тексты, ссылки на проекты) — структура текста в `../references/copywriting.md`.
2. Замени плоские цветовые плашки `.project-card__image--*` на реальные изображения/фото проектов (сохрани индекс `P.0N` и регистрационную метку — это часть системы, не декор).
3. Пересмотри токены в начале `styles.css` (`--paper`, `--ink`, `--blue`, `--red`) под палитру из брифа.
4. Если бриф просит motion-first направление (а не системное) — вернись к обычному каталогу паттернов в `../references/patterns.md` (custom cursor + magnetic, органичный easing, градиенты) вместо этой сетки.
