# AGENTS.md — гайд для AI-агентов по этому репозиторию

Сайт-визитка бренд-дизайнера **Марины Филиной** (псевдоним **WithArt**).
Реальный клиентский проект, деплоится на Vercel как статический сайт.

Repo: `https://github.com/kimci621/marinafilina.ru.git`, ветка `master`.

## Стек и ограничения

- Vanilla HTML/CSS/JS. **Без сборки, без npm, без фреймворка.** Не предлагать React/Vite/бандлер —
  это осознанный выбор, не пробел.
- GSAP 3.12.7 + ScrollTrigger, Lenis 1.1.18 — подключены через CDN прямо в HTML (`<script>` теги),
  версии запинены. Не менять на другой стек анимации.
- Шрифт — Inter (см. `--font` в `styles.css`).
- Деплой на Vercel: **Framework Preset = Other** (No Framework), Build Command и Output Directory
  пустые (или Output = `.`). Root Directory `./`.

## Дизайн-язык

Отль Айхер / Ульмская школа: модульная сетка, единый гротеск, плоские сигнальные цвета,
`border-radius: 0` везде, тонкие hairline-разделители вместо теней и скруглений, номерная разметка
(`P.01`, `C01/R01` и т.п.) как часть визуального языка. Не добавлять тени, градиенты-заливки,
скруглённые углы, декоративные иконки — это ломает стиль.

Токены — в начале `styles.css` (`:root`): `--paper`, `--ink`, `--mute`, `--line`, `--line-strong`,
шкала отступов `--space-1…5`.

Если нужно спроектировать новый раздел в этом духе — см. skill `awwwards-portfolio`
(лежит прямо в репозитории: `.claude/skills/awwwards-portfolio/`), на основе него собран
этот сайт. Claude Code подхватывает project-scoped skills из `.claude/skills/` автоматически.

| `project.html` / `project.js` | Страница кейса, `project.html?slug=<slug>`. Читает `slug` из URL, ищет проект в `C.work.projects`, рендерит галерею и «следующие проекты». |

## Контент и структура данных (`content.js`)

- `brand`, `meta`, `nav`, `hero`, `strip` — шапка/hero/бегущая строка.
- `work.projects[]` — 5 проектов, каждый:
  - `slug`, `index` (`P.01`…), `color` (`a`–`e`, см. таблицу ниже), `title`, `subtitle`,
    `cardDescription`, `services[]`, `description`, `covers[]`, `photos[]`.
  - `covers` — 3 квадратные обложки для карусели на главной (см. «Карусель обложек»).
  - `photos` — вся галерея кейса, элементы `{ src, mobile? }`: `mobile` — вертикальная версия
    того же кадра, показывается через `<picture><source media="(max-width:720px)">` на ≤720px.
  - Если файла нет — `<img onerror>` гасит картинку, остаётся плоская фирменная заливка проекта.
- `work.cta` — CTA-карточка последней в сетке работ (`{ title, linkText, suffix }`), ведёт на `#contact`.
- `about`, `contact` (email, phone, `socials[]`), `footer` (`copyright`, `credit`, `creditHref`).

### Проекты ↔ цвета (жёсткая связка 1:1)

CSS-классы `.project-card__image--a` … `--e` в `styles.css` задают фирменный цвет каждого проекта.
Один и тот же класс используется на карточках главной, в галерее кейса и в блоке «следующий проект» —
поменял цвет в CSS один раз, обновилось всё.

| color | slug | проект | оттенок |
|---|---|---|---|
| a | faculty-amm | Факультет ПММ ВГУ | глубокий фиолетовый |
| b | syntepart | Механический завод Syntepart | тёмно-синий |
| c | fittin | IT-компания Fittin | оранжевый |
| d | flysurf | FLY & SURF | океанический синий |
| e | manipula | Сеть салонов MANIPULA | коралловый |

Цвета подбирались под фирменную гамму каждого проекта (Pantone-подобный подбор + проверка контраста
WCAG для текста поверх фона — у `c` и `e` текст `var(--ink)`, у остальных `var(--paper)`).

Все изображения сайта — `object-fit: contain` (см. `.project-card__photo`), фото не обрезаются.

### Карусель обложек (`setupCoverCycle` в `main.js`)

На карточке проекта на главной 3 обложки (`covers`) сменяются раз в 5 секунд пиксельным переходом
(сетка 8×5, wipe справа налево, `stagger: {from:'end', grid, axis:'x'}`), цвет пикселей — лёгкий тон
фона самого проекта (`getComputedStyle` + `tintWithWhite`). На наведении карусель ставится на паузу
(флаг `hovered`), при уходе курсора — продолжает с того же места.

## Известный артефакт окружения (не баг)

В фоновой/неактивной вкладке браузера (частый случай при автоматизированном тестировании через
claude-in-chrome) прелоадер (`#preloader`, GSAP-твин заливки) замирает на середине, а вместе с ним —
`loading="lazy"` подгрузка картинок (`img.complete` держится `false`, `naturalWidth: 0`) и любые
`setTimeout`/rAF-таймеры (в т.ч. таймер карусели обложек). Это throttling фоновых вкладок в Chrome,
не проблема сайта. Чинится на время теста так:

```js
document.getElementById('preloader')?.remove();
document.querySelectorAll('[data-reveal]').forEach(el => el.classList.add('is-visible'));
```

Для мобильного вьюпорта (375px) `resize_window` не меняет реальный CSS-viewport вкладки — используйте
временный `mobile-test.html` с `<iframe style="width:375px;height:844px">`, указывающий на локальный
сервер, и удаляйте его после теста (в репозитории такого файла быть не должно).

## Локальный запуск

```bash
python3 -m http.server 8791
# http://localhost:8791
```

Порт не принципиален, `8791` — то, что обычно свободно в этом окружении.

## Git-workflow

- Ветка `master`, ремоут — реальный GitHub клиента.
- **Всегда спрашивать перед `git push`** (даже если предыдущий пуш в сессии был одобрен — согласие
  разовое, не на весь чат). Коммитить можно самостоятельно, пушить — только после явного «да».
- Коммит-сообщения на русском, по-человечески, без «Generated with Claude» в заголовке.

## Чего не делать

- Не переписывать на фреймворк/бандлер.
- Не трогать HTML ради правки текста — весь текст в `content.js`.
- Не добавлять тени/скругления/градиенты — конфликт с Aicher/Ulm-языком.
- Не пушить без явного подтверждения пользователя.
- Не оставлять временные файлы (`mobile-test.html` и т.п.) в репозитории после тестов.
