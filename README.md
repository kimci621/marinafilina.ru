# Марина Филина / WithArt — сайт-визитка

Vanilla HTML/CSS/JS + GSAP/Lenis, без сборки. Стиль — Отль Айхер/Ульмская школа
(модульная сетка, единый гротеск, плоские сигнальные цвета). Собран на основе
скилла `awwwards-portfolio`.

## Запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Структура

- `content.js` — весь контент сайта (тексты, ссылки, проекты, контакты). Правки контента — только здесь.
- `brand-mark.js` — SVG-метка «МФ» (переиспользуется в шапке, футере, странице проекта, favicon).
- `index.html` / `main.js` / `styles.css` — главная страница.
- `project.html` / `project.js` — страница кейса (`project.html?slug=<slug>`), рендерится из `content.js`.
- `images/projects/<slug>/` — сюда кладутся фото проектов.
- `images/og-image.png` — картинка для превью при шаринге (og:image).

## Фото

Конвенция путей: `images/projects/<slug>/01.jpg`, `02.jpg`, `03.jpg` — ровно то,
что уже прописано в `content.js` (`work.projects[].photos`). Пока файлов нет —
карточка/галерея показывает плоскую фирменную заливку (цвет проекта) вместо фото:
`<img>` гасится по `onerror`, фон карточки остаётся. Просто положите файлы с
такими именами в нужную папку — картинка появится без правок кода.

## Слаги проектов

`faculty-amm`, `syntepart`, `fittin`, `flysurf`, `manipula` — совпадают с
`marina-landing` (тот же клиент, тот же Figma-файл), так что папки/имена файлов
можно переиспользовать 1:1, если фото уже готовились для того проекта.
